# Tests

All Vitest test files should be stored in this folder.

## Naming

- Use `.test.ts` for non-React tests, such as validation or API-route tests.
- Use `.test.tsx` for React component tests.

## Examples

- `cat-validation.test.ts`
- `cat-list-loading.test.tsx`
- `cat-list-empty.test.tsx`
- `cat-form-errors.test.tsx`

Each developer must add at least three relevant test cases for their assigned Milestone 3 issue.

Run tests locally with:

```bash
npm test
